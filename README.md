# Контакт — импорт таблиц в MySQL

Приложение по ТЗ №3 от 10.09.2026. Стек: PHP 8.3, MySQL 5.7. Интерфейс на русском, рассчитан на одного администратора. Исходный код и PHP-зависимости входят в архив; Composer и SSH на хостинге не требуются.

## Возможности

- Импорт настоящих бинарных XLS, XLSX, CSV и открытого Google-листа по HTTPS-ссылке. Можно выбрать лист Excel, начальную строку, наличие заголовков, кодировку и разделитель CSV.
- Автоматическое предложение соответствий по названиям колонок, включая структуру приложенного примера 2ГИС. Ручной выбор нескольких исходных колонок для каждого из пяти полей.
- Предпросмотр до записи. Сохранение соответствий в именованный шаблон и автоматическое предложение шаблона при повторении той же структуры.
- Хранение исходных значений и нормализованных контактов в MySQL. Виды «Как есть» и «Унифицированная», поиск, страницы по 50 строк.
- Пять итоговых колонок: Компания, Адрес, Телефоны, Почта, Сайт. Ссылки для телефона, почты и сайта.
- Карточка контакта: системный номер, пустые поля «Дата», «Комментарий», «Дата 2», история записей. Номер контакта и номера записей присваиваются автоматически. Из карточки можно позвонить через `tel:`.
- Экспорт всей выбранной базы в XLS и UTF-8 CSV. Отдельная CSV-ссылка для `IMPORTDATA`, создание, перевыпуск и отзыв ссылки.

Приложение обрабатывает готовые выгрузки, а не собирает данные непосредственно из 2ГИС или реестров ОКВЭД.

## 1. Подготовка хостинга

Нужны PHP **8.3**, MySQL **5.7**, HTTPS и расширения PHP: `pdo_mysql`, `mbstring`, `curl`, `zip`, `gd`, `xml`, `dom`, `fileinfo`, `iconv`, `xmlreader`, `xmlwriter`, `simplexml`. Рекомендуемые настройки:

```ini
memory_limit = 512M
upload_max_filesize = 20M
post_max_size = 22M
max_execution_time = 120
```

Хостинг должен разрешать исходящие HTTPS-соединения к Google. PHP/cURL должен использовать действующий набор корневых сертификатов. Проверка сертификатов в приложении включена.

По умолчанию одна загрузка ограничена 20 МБ, 20 000 контактами, 100 колонками и 300 000 ячейками. Распакованный XLSX — не более 80 МБ. Для больших баз разделите файл на части. Повышать лимиты нужно вместе с памятью и временем выполнения хостинга.

## 2. Размещение по FTP/FTPS

Предпочтительный вариант — загрузить папку `contact-importer` целиком и в панели хостинга назначить корнем сайта её подпапку `public`:

```text
contact-importer/
  app/               код приложения
  bin/               необязательные консольные утилиты
  database/schema.sql
  views/             шаблоны страниц
  vendor/            готовые зависимости — обязательно загрузить
  storage/           временные файлы, вне публичного каталога
  config.example.php
  config.php         создаётся вами из образца
  public/            корень сайта
    index.php
    install.php
    assets/
```

Если изменить корень сайта нельзя и хостинг использует Apache 2.4 с разрешёнными `.htaccess`, можно загрузить всю папку в `public_html/contacts/` и открывать `https://ваш-домен/contacts/public/index.php`. Скрытые `.htaccess` из архива обязательно должны попасть на сервер: корневой запрещает доступ к служебным каталогам, а `public/.htaccess` разрешает публичные страницы. Не удаляйте корневой `.htaccess`, чтобы исправить ошибку 403/500.

Для Nginx используйте вариант с корнем сайта в `public`; Nginx не читает `.htaccess`. Если хостинг использует Apache совместно с Nginx, попросите назначить `public` корнем сайта, чтобы служебные файлы не отдавались фронтальным сервером.

При FTP-установке проверяется, что `config.php`, `storage`, `database`, `vendor`, `composer.json` недоступны по HTTP (403/404), а публичные страницы доступны. PHP должен иметь право записи в `storage`. На время установки — также в `config.php`; после установки доступ на запись к конфигурации можно убрать. Не используйте права 777.

## 3. Конфигурация и первый вход

1. Создайте базу MySQL и пользователя в панели хостинга. Для установки нужны права создания таблиц и связей; для работы — чтение, добавление, изменение и удаление данных.
2. Скопируйте `config.example.php` в `config.php`.
3. Заполните блок `db`: хост, порт, имя базы, пользователь и пароль. Значения задаются как строки PHP; апостроф и обратную косую черту в пароле нужно экранировать по правилам PHP.
4. Укажите `app_url`: полный внешний адрес `index.php`, например `https://example.ru/contacts/public/index.php`, без `?` и `#`. От него строится ссылка Google-интеграции.
5. Задайте `admin_login` и случайный `setup_key` минимум из 32 символов. Оставьте `admin_password_hash` равным `CHANGE_ME`.
6. Откройте `install.php` рядом с `index.php`. Введите ключ установки и новый пароль администратора от 12 до 72 байт. Установщик создаст таблицы, запишет хеш пароля и очистит ключ установки.
7. Откройте `index.php` и войдите. После установки можно удалить `public/install.php` с сервера; повторная установка также блокируется программно.

В архиве нет готового производственного пароля и подключения к вашей БД.

Альтернатива при наличии SSH: импортировать `database/schema.sql` через phpMyAdmin либо выполнить `php bin/install.php`, получить хеш командой `php bin/password.php` и прописать его в `config.php`. При обновлении сохраняйте собственный `config.php`, базу и каталог `storage`; не запускайте установку заново.

## 4. Импорт контактов

1. На главной выберите файл **или** вставьте Google-ссылку. При необходимости задайте название базы и настройки CSV.
2. Проверьте выбранный лист и строку заголовков. Для файла без заголовков снимите соответствующий флажок.
3. Отметьте исходные колонки для пяти итоговых полей. Несколько выбранных колонок объединяются в порядке файла. Невыбранные исходные колонки остаются в виде «Как есть».
4. При желании задайте имя шаблона. Его структура включает названия и порядок исходных колонок; схема с переставленными колонками не будет применяться вслепую.
5. Откройте предпросмотр и нажмите «Сохранить контакты». Запись проходит в транзакции: при ошибке частичная база не появляется. Повторная отправка уже завершённой формы не создаёт второй импорт.

В примере «Пример базы.xlsx» распознаны 22 колонки и 21 контакт. Автоматическое соответствие:

| Итоговое поле | Исходные колонки |
| --- | --- |
| Компания | Название |
| Адрес | Город, Регион, Адрес |
| Телефоны | Телефон, Мобильный телефон, whatsapp, viber |
| Почта | Email |
| Сайт | Сайт |

Пустые поля не заполняются вымышленными значениями. Пустые строки пропускаются; строки выше выбранного начала не импортируются. «Как есть» сохраняет порядок колонок и исходные значения строк, но не оформление Excel, объединения ячеек, макросы или вычислительную модель книги. Формулы Excel не выполняются: используется сохранённый результат, а при его отсутствии — текст формулы.

Нормализация телефонов удаляет пробелы, скобки и разные виды тире, переводит 11-значный российский номер с `8` в `+7`, а к 10-значному добавляет `+7`. Международные номера с явным плюсом сохраняют код страны. Добавочные номера поддерживаются. Повторы внутри одного контакта убираются; одинаковые компании в разных строках и повторных загрузках сохраняются отдельными записями. Нераспознанные значения нужно проверять по исходной таблице. Повторный импорт Google-ссылки создаёт новую базу; фоновая синхронизация не включена.

## 5. Google Таблицы

Для входящего импорта включите у исходной таблицы просмотр по ссылке либо опубликуйте лист. Поддержаны обычные адреса `/spreadsheets/d/.../edit#gid=...` и опубликованные `/spreadsheets/d/e/.../pub?...`. Закрытую таблицу загрузите файлом; OAuth и доступ к закрытому Google-аккаунту в эту версию не входят.

Для исходящего экспорта откройте сохранённую базу и нажмите «Создать CSV-ссылку». Скопируйте готовую формулу в A1 пустого листа Google:

```text
=IMPORTDATA("https://example.ru/contacts/public/index.php?a=feed&token=...")
```

Обёртка `HYPERLINK` здесь не нужна: `IMPORTDATA` принимает URL непосредственно. Можно использовать и конструкцию из ТЗ `=IMPORTDATA(HYPERLINK("..."))`, но интерфейс выдаёт короткую форму.

CSV-ссылка доступна без входа только по случайному 256-битному токену. В БД хранится хеш токена. Полный URL отображается в текущей сессии после создания: сохраните его до выхода. Перевыпуск делает старую ссылку недействительной; отзыв блокирует доступ. Уже импортированные Google данные отзыв не удаляет, обновления могут задерживаться из-за кэша Google. Ссылка выгружает всю выбранную базу, независимо от поиска на странице.

CSV использует запятую, UTF-8 и стандартное экранирование кавычками. Скачиваемый файл содержит BOM для Excel; поток для Google — без BOM. Для защиты от формул потенциально вычисляемые значения (включая ведущий `+` телефона) получают текстовый префикс `'`; некоторые CSV-клиенты показывают его явно. В XLS все ячейки записаны как текст без добавления префикса, поэтому знак `+` и исходные номера сохраняются буквально.

Документация: [IMPORTDATA](https://support.google.com/docs/answer/3093335?hl=ru), [доступ к Google-листам по ссылке](https://developers.google.com/chart/interactive/docs/spreadsheets), [чтение таблиц PhpSpreadsheet](https://phpspreadsheet.readthedocs.io/en/latest/topics/reading-files/).

## 6. Обслуживание

- `phone_action = 'form'` открывает карточку при нажатии на телефон; `'dial'` открывает `tel:`. Карточка также доступна по названию компании.
- Временный предпросмотр действует два часа. Его файлы удаляются после успешного импорта; просроченные — при следующей загрузке. Незавершённые предпросмотры не являются сохранёнными контактами.
- Делайте резервную копию базы и `config.php`. Рабочие данные хранятся в таблицах `ci_imports`, `ci_leads`, `ci_templates`, `ci_notes`, `ci_feeds`; `ci_login_attempts` содержит счётчики попыток входа.
- Ошибки сервера пишутся в журнал PHP с кодом; SQL и секреты подключения не выводятся в интерфейс. Ошибки входных данных отображаются пользователю.
- На странице баз показаны последние 100 загрузок. Каждая сохранённая база имеет постоянный адрес по её системному номеру.
- Не включайте публичный доступ к MySQL. Приложению достаточно подключения с хостинга.

## Проверка и разработка

Зафиксированные версии библиотек — в `composer.lock`. При изменении зависимостей на машине разработчика: `composer install --no-dev --prefer-dist`, затем снова передать `vendor` на хостинг. Лицензии библиотек сохранены в `vendor`.

Базовые проверки без MySQL:

```text
php tests/unit.php
php tests/unit.php "/путь/к/Пример базы.xlsx"
```

Результаты выполненной проверки — в `TEST-REPORT.md`. Для завершения установки на вашем сервере нужны адрес сайта, каталог размещения, FTP/FTPS-доступ и параметры MySQL. До их получения приложение проверено локально, но на ваш хостинг не развёрнуто.
